# Unemployment Analysis with Python

A CodeAlpha Task 2 script that generates illustrative India unemployment data and creates summary statistics and charts for national trends, regions, urban/rural comparisons, monthly patterns, COVID-era phases, and correlations.

## Data note

The script generates synthetic sample data in code; it does not load an official unemployment dataset. Its charts and findings are examples, not measured labour statistics. The repository name `CodeAlpha_CarPricePrediction` does not match the unemployment-analysis script currently stored here.

## Requirements

Python 3 and these packages: `numpy`, `pandas`, `matplotlib`, and `seaborn`. The repository does not currently include a dependency lockfile or `requirements.txt`.

Install the packages and run the script from this directory:

```sh
python -m pip install numpy pandas matplotlib seaborn
python task2_unemployment_analysis.py
```

The script prints its summary and writes chart PNG files into the current working directory.
